# OIBSIP-Autocomplete-Autocorrect-NLP
An NLP-based Autocomplete and Autocorrect system using Bigram, Trigram, and Levenshtein Edit Distance, featuring an interactive Streamlit dashboard. Developed for Oasis Infobyte Data Analytics Internship.
Autocomplete & Autocorrect NLP Dashboard

Oasis Infobyte | Data Analytics Internship | Level 2 – Task 5

Overview

An interactive NLP application built using the WikiText-2 dataset to predict the next word and correct spelling errors.

Features

Bigram and Trigram autocomplete

Levenshtein edit-distance autocorrect

Precision, Recall, and Accuracy evaluation

Interactive Streamlit dashboard

Word-frequency analysis and model comparison

Tech Stack

Python | Pandas | NLTK | Scikit-learn | Plotly | Streamlit
